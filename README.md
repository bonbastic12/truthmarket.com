# Official platform logos

Put the official logo of each platform here as an SVG with exactly these names:

    youtube.svg   instagram.svg   tiktok.svg   telegram.svg   facebook.svg

They replace the plain icons in the marketplace filter, listing cards, the sell form and the header automatically.
Until a file exists, the plain icon is shown.

Get each logo from the platform's own brand or press page and follow its usage rules (clear space, no recoloring,
no suggestion that the platform endorses Truth Market):

- YouTube: youtube.com/howyoutubeworks/resources/brand-resources
- Instagram / Facebook: about.meta.com/brand/resources
- TikTok: tiktok.com/brand-guidelines (or its Newsroom assets)
- Telegram: telegram.org/tour/screenshots (brand assets) or core.telegram.org/api/terms

Square or round logos work best. Keep the file small (a few KB).
